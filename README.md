# CAPSTONE PROJECT: Financial Performance Analysis of Publicly Listed Fashion Companies (2020-2025)

Author: Anne M Date: 4 September 2026

This Capstone Project for the Google Data Analytics Certificate course follows the six step data analysis process:

Ask – define the business problem
Prepare – gather data
Process – clean the data
Analyse – analyse to find the insights
Share – share the results
Act – turn insights into decisions
